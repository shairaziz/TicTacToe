# Tic-Tac-Toe — x86 Assembly

A basic single-player Tic-Tac-Toe game (Player vs Computer) built in x86 Assembly, developed for EMU8086.

## Features

- Formatted 3×3 board display
- Basic AI logic (wins when opening or blocks player moves or picks randomly)
- Single-player mode (vs Computer)
- Win/draw detection system
- Turn indicator showing whose turn it is (Player/Computer)
- Scoreboard and Replay option via a menu system

## Tech Stack

- **Language:** x86 Assembly
- **Emulator/Environment:** EMU8086

## How to Run

1. Download and install [EMU8086](https://emu8086-microprocessor-emulator.en.softonic.com/) 
2. Open the `.asm` file in EMU8086.
3. Compile and run (Emulate) the program.
4. Follow on-screen prompts to play against the computer.
